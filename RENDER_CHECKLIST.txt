🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "Build failed" error
SOLUTION:
  1. Check the build logs (red error messages)
  2. Common causes:
     - Typo in Build Command
     - Missing dependency in requirements.txt
     - Syntax error in Python code
  3. Fix the issue
  4. Git push again or click "Redeploy" in Render

PROBLEM: "ALLOWED_HOSTS" error when visiting
SOLUTION:
  1. Update ALLOWED_HOSTS in Render Environment variables
  2. Must match your exact Render URL
  3. Click "Save"
  4. Wait for auto-redeploy

PROBLEM: Page shows "502 Bad Gateway"
SOLUTION:
  1. This usually means Render is still deploying
  2. Wait 1-2 minutes
  3. Refresh page
  4. If still broken, check logs in Render dashboard

PROBLEM: Static files (CSS/Images) not loading
SOLUTION:
  1. This means collectstatic didn't run
  2. In Render, click "Redeploy" button
  3. If issue persists, SSH into server and run:
     python JokesProject/manage.py collectstatic --noinput

PROBLEM: Need to see what went wrong
SOLUTION:
  1. Go to Render dashboard
  2. Click your service
  3. Click "Logs" tab
  4. Red text = errors
  5. Copy error and search for solution
